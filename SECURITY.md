# Security Policy

This policy applies to all repositories under the [Across Report (ACR)](https://github.com/acrossreport) organization, unless a repository provides its own `SECURITY.md`.

## Reporting a Vulnerability

If you believe you've found a security vulnerability in any ACR project, please report it privately rather than opening a public issue.

Contact us at:

- across.support@gmail.com
- support@acrossreport.com

Please include:

- The affected repository and version/commit
- A description of the vulnerability and its potential impact
- Steps to reproduce (a minimal example is appreciated)

We will acknowledge your report as soon as possible and keep you updated as we investigate and address the issue. Please allow us reasonable time to respond before any public disclosure.

## Supported Versions

Most ACR projects are distributed as rolling releases (latest version only). Security fixes are applied to the most recent release unless stated otherwise in a specific repository.
